# Your photographs

Put your final WebP, AVIF, JPEG or PNG files in this directory. Then edit
`public/data/gallery.json`: use `/gallery/your-file.webp` for `src` and update
its title, location, year and other metadata. No component changes are needed.

The current collection uses images already in `public/images/`. They are clearly
labelled sample content, including existing artwork and film/book images, rather
than claims about personal photographs. You can replace or remove every sample.

See `docs/memory-gallery.md` for a complete example, optional responsive sizes,
frame orientations, connections and maintenance notes.
